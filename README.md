# RACINGDOWNLOADER

แอปดาวน์โหลดคลิปและเพลงแบบ All-in-One จาก YouTube, TikTok, Facebook, Reels และเว็บอื่นๆ เขียนด้วย Python (CustomTkinter + yt-dlp) เน้นหน้าตาคลีนๆ โหลดไว และแก้ปัญหาจุกจิกเรื่องภาษาบน Windows

---

## จุดเด่น
- วางลิงก์ได้ลื่นๆ: กด Ctrl + อ (Ctrl+V บนคีย์บอร์ดไทย), Win + V หรือคลิกขวาเพื่อวางลิงก์ได้ทันที ไม่ต้องคอยสลับภาษาแป้นพิมพ์
- วิดีโอชัดสูงสุด 4K / 60 FPS: ดึงไฟล์ภาพและเสียงคุณภาพสูงสุดมารวมเป็นไฟล์ .mp4 ให้อัตโนมัติด้วย FFmpeg
- สายฟังเพลงก็มี: แปลงเป็นไฟล์เสียง MP3 (สูงสุด 320 kbps) หรือ WAV (24-bit / 96 kHz) ได้ในคลิกเดียว
- ไม่โหลดวน: วางลิงก์ติดเพลย์ลิสต์มา โปรแกรมจะดึงเฉพาะคลิปนั้นๆ ไม่โหลดมายกอัลบั้มให้รกเครื่อง
- 2 ภาษา (TH / EN): มีสวิตช์เลือกภาษามุมซ้ายบน เปลี่ยนข้อความทั้งแอปได้เรียลไทม์
- แต่งสไตล์ Cordia New: คุมฟอนต์ Cordia New ทั้งโปรแกรม พร้อมปุ่มสลับ Dark / Light Mode
